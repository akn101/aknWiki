# Slate

| | |
|---|---|
| URL | https://slate.gaodi.akn.org.uk |
| Description | Internal workspace for developing an Amazon product, from market research through to listing copy |
| Access | Accounts are issued by an administrator. Registration is closed |
| Pricing | Internal system. No charge to users |

## Overview

Slate allows staff to develop one product at a time through six ordered stages.
Each stage holds a conversation with a model and a set of files. The model reads
the project files, runs research and analysis, and writes new files that the
next stage reads. Access and review controls are available and can be set by
administrators.

Slate is an internal system for GDDigital and OMG Electronics. The interface is
Chinese by default and carries an English toggle. Text intended for customers is
produced in English.

| Capability | Availability |

| Create a project for a product | Any account holder |

| Comment on a file | Project members other than viewers |
| Approve or reject a submitted artifact | Reviewers and admins |
| Add and edit custom skills | Reviewers and admins |
| Manage users, roles, connections and brand kits | Admins |
| View usage and spend | Admins |

| Price, rating and stock alerts | Not available |
| Enter connector keys in the browser | Not available |

## Workflow stages

A project holds generations. A generation passes through the six stages in
order. Stages may be revisited and repeated.

| Number | Stage | Produces |
|--------|-------|----------|
| 1 | Design | A product specification |
| 2 | Analyse | Competitor pool, market research, profit model, entry recommendation |
| 3 | VOC | Pain point report and a dataset for the factory |
| 4 | Iterate | A revised specification version |
| 5 | Generate | Listing copy, product images and a user manual |
| 6 | Reflect | Not available |

## Roles

Every account holds one role. Roles are set by an administrator.

| Role | Grants |
|------|--------|
| Operator | Projects, stage conversations, stage pipelines, files, the job queue |
| Reviewer | Everything an operator holds, plus the review inbox, the skills library, report templates and feedback triage |
| Admin | Everything a reviewer holds, plus users, roles, connections, model routing, brand kits, the organisation directory, usage and spend |

A project also carries its own member list. A project member holds one of four
project roles: operator, reviewer, admin or viewer. A viewer reads the project
and cannot comment on its files.

## Signing in

Slate loads the sign-in screen for any visitor without a session.

### With a password

1. Enter the email address of the account.
2. Enter the password.
3. Select **Sign in**.

### With a mobile verification code

The **Phone code** tab appears when the organisation has enabled code sign-in.

1. Select **Phone code**.
2. Enter the mobile number. Mainland China numbers only.
3. Select **Send code**.
4. Enter the six digit code. Codes remain valid for five minutes.
5. Select **Sign in**.

A number must be bound to an account before it can sign in. Bind a number under
**Settings** then **Profile**.

### With WeCom

Select **Sign in with WeCom**. The button appears when the organisation has
configured WeCom sign-in.

## Session and password

| Property | Detail |
|----------|--------|
| Session length | Seven days from sign-in |
| Language | Set from the toggle in the sidebar footer. The setting is per browser |
| New accounts | Created by an administrator with a temporary password shown once |
| Password change | **Settings** then **Profile**. Minimum eight characters |

Change a temporary password at first sign-in. The administrator who created the
account has seen it.
