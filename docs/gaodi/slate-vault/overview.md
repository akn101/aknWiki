# Slate Vault

| | |
|---|---|
| Description | Document store holding every file Slate produces and every file an operator uploads |
| Access | Restricted. Contents are commercial and internal. Uploaded originals may carry customer data and must not be published |
| Pricing | Included with Slate |

## Overview

Slate Vault allows users to read, search, and edit every document a project
produces, held as one folder of ordinary files. Access controls are available
and can be set by the organisation.

The vault has two writers. Slate records each stage output and each upload as a
new file. The operator opens the same folder in Obsidian and edits the text.

## What the vault holds

| Folder | Holds |
|--------|-------|
| `brands` | Brand kits: voice and tone, colour palette, reference images |
| `projects` | One entry per project, holding its uploads and its stage outputs |

Every document is Markdown or a plain data or image file. No document requires
Slate to open it.

## Capabilities

| Capability | Availability |
|------------|--------------|
| Read every document of a project in one place | Operators with vault access |
| Edit the text of a document in Obsidian | Operators with vault access |
| Add your own metadata fields to a document | Operators with vault access |
| Rename, edit, or remove uploaded originals | Operators with vault access |
| Add a brand kit by hand | Operators with vault access |
| Retain every earlier version of a document | Automatic |
| Record who changed a document and when | Automatic |
| Add a new version by renaming a file | Not available |
| Rename a document written by Slate | Not available |
| Move a document written by Slate into another folder | Not available |
| Two people editing one document at the same time | Not available |

## Version history

| Property | Detail |
|----------|--------|
| New versions | Written as a new file with the next version number |
| Earlier versions | Kept. Slate never overwrites a numbered document |
| The project record | Rewritten in place. It carries no version number |
| Authorship | Each change records the person who made it and the time |
| Deletion | Removing a file removes it from Slate at the next read |

## Confidentiality

| Property | Detail |
|----------|--------|
| Uploaded originals | Stored exactly as supplied, including any personal data in them |
| Reports produced by Slate | Written from anonymised data. Reviewer names and profiles are not carried through |
| Distribution | Internal only. The vault must not be placed on a public host |
