# EC Timetable Viewer

| | |
|---|---|
| URL | https://tt.ec.playground.akn.me.uk |
| Description | Turns a saved Eton College timetable into an interactive weekly view and a calendar file |
| Access | Public. No sign-in required. A playground experiment maintained on a best-effort basis |
| Pricing | Free |

## Overview

The EC Timetable Viewer allows Eton College students to open their timetable
as a weekly view and export it to a calendar application. The timetable is
supplied as an HTML file saved from the student portal.

The weekly view shows lesson time, subject, teacher, and room, together with
counts for the week. Export produces a standard calendar file for Google
Calendar, Apple Calendar, Outlook, and similar applications.

## Capabilities

| Capability | Availability |
|------------|--------------|
| Load a timetable saved as an HTML file | Any visitor |
| View the week by day, colour coded | Any visitor |
| See lesson time, subject, teacher, and room | Any visitor |
| See counts of lessons, free periods, subjects, and teachers | Any visitor |
| See full teacher names in place of codes | Where the name is known |
| See Early Work indicators | Any visitor |
| See the current school letter | Any visitor |
| Export selected weeks or a date range to a calendar file | Any visitor |
| Load a Web Archive file | Not available |
| Load an MHTML file | Not available |
| Load a timetable from a school other than Eton College | Not available |
| Retrieve the timetable from the portal directly | Not available. The file is saved and supplied by the student |

## File handling

| Property | Detail |
|----------|--------|
| Accepted file | The timetable page saved as HTML only, or as page source |
| Upload to a server | None. The file is processed in the browser |
| Account requirement | None |

## Support status

The viewer is a playground project maintained on a best-effort basis. It reads
the Eton College timetable format only.
