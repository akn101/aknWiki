# Calendar export

A loaded timetable can be exported to a calendar file and imported into a
calendar application.

## Export format

The export is a standard iCalendar file (`.ics`), accepted by all major
calendar applications.

## Choosing what to export

| Option | Effect |
|--------|--------|
| Select specific weeks | Includes only the weeks chosen |
| Date range | Includes lessons between a start and an end date |

## Importing the file

Import the exported file using the calendar application's own import
function.

| Application | Path |
|-------------|------|
| Google Calendar | Settings, then Import and Export, then Import |
| Apple Calendar | File, then Import |
| Outlook | File, then Open and Export, then Import and Export, then Import an iCalendar file |
