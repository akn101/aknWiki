# aknThoughts

| | |
|---|---|
| URL | https://thoughts.akn.me.uk |
| Description | Public bulletin board for short notes, with moderated publishing |
| Access | Public read and submit. Moderation restricted by akn ID scope |
| Pricing | Free |

## Overview

aknThoughts allows users to post short notes publicly on a bulletin board.
Access and review controls are available and can be set by the organisation
using akn ID scopes.

Submissions are held for approval before publication. Notes carry no author
identity and no account is required to read or submit.

## Capabilities

| Capability | Availability |
|------------|--------------|
| Read published notes | Any visitor |
| Submit a note | Any visitor |
| Approve or reject submissions | akn ID scope holders |
| Publish without review | akn ID scope holders |
| Remove a published note | akn ID scope holders |
| Edit a note after submission | Not available |
| Delete your own note | Not available |
| Search or filter the board | Not available |

## Publication model

Notes occupy one of three states.

| State | Visible to | Set by |
|-------|-----------|--------|
| Submitted | Scope holders | Any visitor |
| Rejected | Nobody. The note is deleted | Scope holders |
| Published | Any visitor | Scope holders |

No timeframe applies to review. No notification is issued in either direction.

## Privacy

| Property | Detail |
|----------|--------|
| Author identity | Not collected and not stored |
| Account requirement | None for reading or submitting |
| Traceability | A submitted note cannot be linked to its author or claimed later |
| Timestamps | Recorded at submission, discarded on publication |
