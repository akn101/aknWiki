# Installing

The page can be installed as an application on desktop and mobile. Installation
is optional and changes nothing about what the page can do.

## Desktop

1. Open https://startpage.akn.me.uk.
2. Select the install control in the browser address bar.
3. Confirm.

The application opens in its own window with no address bar and no tabs.

## iPhone and iPad

1. Open https://startpage.akn.me.uk in Safari.
2. Select **Share**.
3. Select **Add to Home Screen**.
4. Confirm.

## Android

1. Open https://startpage.akn.me.uk.
2. Open the browser menu.
3. Select **Install app** or **Add to Home screen**.
4. Confirm.

## Setting it as the new tab

The page can also be used without installing.

| Setting | Value |
|---------|-------|
| Homepage | https://startpage.akn.me.uk |
| New tab | https://startpage.akn.me.uk |

Some browsers do not allow the new tab page to be changed without an extension.

## What changes once installed

| Property | Installed | In a browser tab |
|----------|-----------|------------------|
| Window | Full screen, no browser controls | Normal tab |
| Icon | Application icon on the desktop or home screen | Browser icon |
| Zoom | Disabled | Disabled |
| Session | 30 days from sign-in | 30 days from sign-in |
| Keyboard shortcuts | Unchanged | Unchanged |

## Offline

The page opens without a connection. Whatever was loaded last is shown.

| Content | Offline behaviour |
|---------|-------------------|
| The page itself | Opens from the device |
| Widget data | The last received values, up to 24 hours old |
| Clock and background | Continue to work |
| Adding todos, habits, alarms | Fails. Marking a habit appears to work and is lost on the next refresh |
| Search and quick links | Fail. Both require a connection |
| Sign-in | Not possible |

When a connection is slow, the page waits ten seconds before falling back to
stored data.

## Updates

The page checks for a new version every 30 minutes and reloads itself once
there has been no input for ten minutes. Reloading manually applies a new
version immediately.
