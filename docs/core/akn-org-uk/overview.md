# akn.org.uk

| | |
|---|---|
| URL | https://akn.org.uk |
| Description | Single page company site for AKN Systems Ltd, listing its live products and its contact address |
| Access | Public. No account and no sign-in |
| Pricing | Free |

## Overview

akn.org.uk allows visitors to read what AKN Systems Ltd builds, open each of
its live products, and reach the company by email. All content sits on one
page, divided into sections reachable from the header.

The site publishes information only. No field on the page accepts input and no
part of it is restricted.

## Capabilities

| Capability | Availability |
|------------|--------------|
| Read the company and product descriptions | Any visitor |
| Open a linked product site | Any visitor |
| Start an email to the company | Any visitor |
| Jump to a section from the header | Windows 620 pixels wide and above |
| Replay the opening animation | Any visitor, by address |
| Adjust the hero artwork | Any visitor, through the tuner panel |
| Sign in or create an account | Not available |
| Contact form | Not available. Contact is by email |
| Search | Not available |
| Language selection | Not available |
| Light and dark theme choice | Not available. One fixed palette |
| Downloadable documents | Not available |
| News, blog, or dated updates | Not available |

## Sections

| Section | Contents |
|---------|----------|
| Start | Company positioning and two contact routes |
| Products and work | One card per live product |
| How we work | Three statements of method |
| What AKN does | Four areas of work |
| The company | Company statement, founder, contact address |
| Footer | Product links, contact address, registration details |

Four header links cover these sections. **Approach** covers both How we work
and What AKN does.
