# Using the site

Everything published on akn.org.uk sits on one page. Reading requires no
account.

## Moving through the page

Scroll, or select a link in the header. Header links scroll to their section
rather than loading a new page.

| Header link | Moves to |
|-------------|----------|
| **Start** | Top of the page |
| **Products** | The product cards |
| **Approach** | How we work |
| **Company** | The company statement and contact address |

| Property | Detail |
|----------|--------|
| Header | Fixed to the top of the window while scrolling |
| Current section | Underlined in the header |
| Position in the page | Shown as a fill across the bottom edge of the header |
| What AKN does | Carries no header link. **Approach** stays marked while it is on screen |
| Header links below 620 pixels wide | Hidden. Scroll instead |

## Opening a product

The Products and work section holds one card per product. Selecting anywhere on
a card opens that product.

| Product | Address |
|---------|---------|
| Agora | https://agora.akn.org.uk |
| The Pathway Initiative | https://tpi.akn.org.uk |
| AKN ID | https://id.akn.me.uk |

The same three products are listed again in the footer.

| Route | Opens in |
|-------|----------|
| Card in Products and work | A new tab |
| Link in the footer | The same tab |

## Contacting the company

Every contact control on the page addresses `enquiries@akn.org.uk`. Selecting
one starts a new message in the default mail application.

| Location | Label |
|----------|-------|
| Header, right side | **Start a conversation** |
| Start section | **Start a conversation** |
| The company section | **enquiries@akn.org.uk** |
| Footer | **Let's build something unusual.** |

No contact form, phone number, or messaging channel is published.

## The name band

A band between the first two sections scrolls the names Agora, The Pathway
Initiative, AKN ID, Agentic operations, and Founder infrastructure. The band is
decorative and its names are not links. Holding the pointer over it pauses the
scroll.
