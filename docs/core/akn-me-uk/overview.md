# akn.me.uk

| | |
|---|---|
| URL | https://akn.me.uk |
| Description | Personal site holding projects, experiments, photography, and letters, with parts of it gated |
| Access | Public. Selected projects, experiments, and letters require an access code or an akn ID sign-in |
| Pricing | Free |

## Overview

akn.me.uk allows visitors to read about Ahnaf Kabir, browse his projects,
experiments, photography, and letters, and make contact. Access controls are
available over individual projects, experiments, and letters, granted by a five
digit access code or by an akn ID sign-in.

Sections are reached from a side menu or from a command palette. Entries a
visitor cannot see are absent rather than marked, and appear in place once
access is granted.

## Capabilities

| Capability | Availability |
|------------|--------------|
| Browse projects, experiments, photography, and letters | Any visitor |
| Search across sections, projects, and experiments | Any visitor, through the command palette |
| Copy the contact address | Any visitor |
| Draft a message and hand it to a mail application | Any visitor |
| Switch between light and dark | Any visitor whose device reports a dark colour scheme |
| View protected projects and experiments | Access code holders, and akn ID accounts granted access |
| Read restricted letters | Access code holders, and akn ID accounts holding the matching group |
| Filter by state | Work section only |
| Search within a section | Not available |
| Comment on a letter | Not available |
| Subscribe to updates | Not available |
| Create an account on this site | Not available |
| Sign out of granted access | Not available |
| Send a message from the site itself | Not available |

## Sections

| Section | Path | Contents |
|---------|------|----------|
| Entry | `/start` | Opening screen. Advances to Home |
| Home | `/home` | Clock, location panel, introduction, latest experiment |
| Work | `/work` | Projects, filterable by state |
| Flair | `/flair` | Interactive, audio, video, and image experiments |
| Photography | `/photography` | Photograph grid with a full size viewer |
| Letters | `/letters` | Written pieces, some of them restricted |
| About | `/about` | Biography and current activity |
| Contact | `/contact` | Address, message box, and external profiles |

Entering https://akn.me.uk sends the visitor to the entry screen.

## Access model

| Method | Grants | Duration |
|--------|--------|----------|
| Access code | The projects, experiments, and letters that code covers | 24 hours from entry |
| akn ID sign-in | Whatever the account's groups cover. Administrator accounts receive everything | 1 hour, renewed while the akn ID session stands |
| Access code entered while signed in with akn ID | The same items, held against the account | Retained on the account |

Neither method creates an account on this site.
