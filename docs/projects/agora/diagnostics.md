# Diagnostics

Observed conditions and their resolutions.

## Reading the site

| Condition | Cause | Resolution |
|-----------|-------|------------|
| The top bar shows no menu on a phone | The links are hidden on narrow screens and no menu button is offered | Scroll the home page, or use the links at the foot of the page |
| No way to change language | The site is published in English only | Use the translation feature of your browser if it has one |
| No search box | The site has no search | Scroll the home page. It holds every section |
| A screen reader announces the two app pictures as Groups and Chat | The descriptions attached to the pictures do not match the screens shown | Disregard them. The pictures show a welcome screen and a sign in screen |
| No governance documents or annual report on the site | Neither is published | Request them by email |

## Contacting the charity

| Condition | Cause | Resolution |
|-----------|-------|------------|
| **Contact Us** does nothing | No email program is set up on the device | Write to `agora.project@akn.org.uk` from any email account |
| No email address printed anywhere on the page | The address is placed into the message rather than shown on the page | Use `agora.project@akn.org.uk` |
| The new message already contains text | The button fills in a subject and a short template | Replace the template with your own words before sending |
| The message was sent by mistake | Sent email cannot be recalled | Send a second message asking the charity to disregard the first |
| No reply | No response time is published | Wait, then send the message again |
| No phone number or postal address | Neither is published on the site | Email is the only route the charity publishes |

## The mobile app

| Condition | Cause | Resolution |
|-----------|-------|------------|
| No download link on the site | The app is not distributed from the website | Email the charity to ask about access |
| An app store search finds nothing | No listing is linked from the site | Email the charity to ask about access |
| The sign in screen asks for a username you do not have | Accounts are not created on the website | Ask the charity how to obtain an account |
| The language you need is not confirmed anywhere | The list of app languages is not published | Ask the charity before relying on it |

## Staff sign-in

| Condition | Cause | Resolution |
|-----------|-------|------------|
| **Staff Login** asks for details you do not have | The link is for charity staff | Community members do not need it |
| Selecting **Staff Login** leaves the Agora site | The staff area sits at a separate address | Return using the back control of your browser |

## Escalation

Conditions not resolved by the above should be reported to the charity by
email. Include the address of the page, the device you used, and what you
expected to happen.
