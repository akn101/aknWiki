# Your information

The website asks visitors for nothing. It has no account, no form, and no
field to type into.

## What the website asks for

| Item | Asked for |
|------|-----------|
| Name | No |
| Email address | No |
| Phone number | No |
| Location or address | No |
| Country of origin or language | No |
| Immigration or asylum status | No |
| Account name or password | No |
| Payment details | No |

Reading the site does not tell the charity who you are.

## What using Contact Us reveals

The **Contact Us** button prepares a message in your own email program. It
sends nothing on its own.

| Item | Detail |
|------|--------|
| Who receives the message | The Agora charity |
| What the charity sees | Your email address, the name held on your email account, and everything you write |
| When it is sent | Only when you send it yourself |
| Protection in transit | Ordinary email. Treat it as readable by others |
| Cancelling | Close the message without sending it. Nothing reaches the charity |
| Withdrawing a sent message | Not possible |

## Before you write

| Advice | Reason |
|--------|--------|
| Keep personal details to a minimum | Ordinary email is not a private channel |
| Do not attach identity or immigration documents | A copy stays in your sent folder and in the charity's inbox |
| Do not describe your asylum case | The charity publishes no secure route for case information |
| Write from an account only you can open | Anyone with access to that account can read the reply |
| Use a shared or public computer with care | Signing out of your email afterwards prevents the next person reading it |

## Privacy in the mobile app

| Area | Detail |
|-------|--------------|
| Data collection | Minimal |
| Location | Not precise. Used to connect people in the same area |
| Messaging | End to end encrypted |
| Moderation | Content checked automatically for harm |
| Verification | Members verify each other |

The site states both that messaging is encrypted end to end and that content
is moderated automatically. How the two work together is not published. Ask
the charity before relying on either claim.

## Links away from the site

| Link | Where it goes |
|------|---------------|
| **Staff Login** | A separate site for charity staff |
| **akn.org.uk** | The organisation that built the site |

The Agora site does not control either destination.
