# The mobile app

The Agora mobile app is described on the website. It is not distributed from
the website.

## Getting the app

| Question | Answer |
|----------|--------|
| Download link on the site | None |
| App store listing linked from the site | None |
| Sign-up on the site | Not available |
| Invitation or waiting list on the site | None |
| How to ask about access | Email the charity |

[Using the site](using.md) covers how to send that email.

The site records one pilot, run in Slough during 2025 with Slough Refugee
Support. It names no other place where the app is in use.

## What the app offers

| Area | Description |
|------|----------------------|
| Group discovery | Join or create groups based on language, nationality, gender, age, and location |
| Secure chat | Messaging in your own language, described as end to end encrypted |
| Event hosting | Propose and attend meetings in person, such as cultural events, language practice, and local walks |
| Safety | Verification by other members, automatic moderation of content, and a panic button for meetings in person |
| Multilingual | Setting up your account in the language you prefer, with groups filtered to people who speak it |
| Privacy | Little data collected, location that is not precise, and encryption throughout |

## Languages

| Item | Detail |
|------|--------|
| Website | English only. No translation and no language selector are offered |
| App | A language selector appears on the welcome screen. Which languages it lists is not published |

## Screens shown on the site

Two pictures of the app appear on the home page.

| Picture | What it shows |
|---------|---------------|
| First | A welcome screen with **Get started**, **Already have an account?**, and a language selector set to English |
| Second | A sign in screen with a username field, a password field, **Let's go!**, and **Forgot Password** |

Sign in uses a username and a password. No other sign in method appears in the
pictures.
