# The Pathway Initiative

| | |
|---|---|
| URL | https://tpi.akn.org.uk |
| Description | Free tutoring in maths, chemistry, English, and modern languages, delivered online by volunteers |
| Access | Public. No account required. Tutoring is offered subject to eligibility |
| Pricing | Free |

## Overview

The Pathway Initiative allows students to request free tutoring in a fixed set
of subjects, and allows volunteers to offer their time as tutors. Both are
requested through a form on the site. The service assigns tutors to students.

Sessions run online by video call. The site carries no booking, scheduling, or
account features. Everything after the application is arranged directly between
the service and the student.

The service was founded in 2024 and is run by volunteers.

## Capabilities

| Capability | Availability |
|------------|--------------|
| Read the site and the FAQ | Any visitor |
| Apply for tutoring | Any visitor |
| Offer to volunteer as a tutor | Any visitor |
| Contact the service by email | Any visitor |
| Create an account or sign in | Not available. The site has no accounts |
| Book, reschedule, or cancel a session on the site | Not available. Arrange this with your tutor |
| Choose your own tutor | Not available. The service matches students to tutors |
| Check the status of an application | Not available |
| View, edit, or withdraw a submitted application | Not available |
| Join a session through the site | Not available. Sessions run on a separate video call |
| Pay for tutoring | Not applicable. The service is free of charge |

## Subjects

| Subject | Offered |
|---------|---------|
| Mathematics | Yes |
| English, including English as a second language | Yes |
| French | Yes |
| Spanish | Yes |
| German | Yes |
| Italian | Yes |
| Chemistry | Yes |
| Any other subject | Not available |

The application form and the site footer both list all seven subjects. The FAQ
lists five and omits Italian and chemistry. Select the subject on the
application form if it appears there.
