# Using the app

The map works without an account. Nothing in this page requires signing in.

## The map

Opening the app draws every docking station in London immediately. The station
list is bundled with the app, so the map does not wait for the network. Live
counts arrive a moment later.

| Circle | Meaning |
|--------|---------|
| Green | Standard bikes are available |
| Blue | Only e-bikes are left |
| Grey | No bikes, or the count has not arrived yet |
| Ring around the circle | How full the docking station is |

Zooming out replaces the circles with small dots. Names appear beneath the
circles once the map is zoomed in far enough.

## Finding where you are

1. Allow location access when the app asks.
2. Select the location button above the bottom panel.

| State of the button | Meaning |
|---------------------|---------|
| Filled | The map is following your location |
| Not filled | The map has been moved since you last centred it |

Moving the map at all, by any amount, stops it following you. Select the
button again to resume.

The map centres your location within the part of the map you can actually
see, not behind the bottom panel.

## The bottom panel

The panel lists the docking stations in view, nearest first. It has three
heights. Drag the handle to change it.

| Height | Shows |
|--------|-------|
| Collapsed | The heading and one or two docking stations |
| Middle | Roughly five docking stations |
| Expanded | The full list |

The list updates once the map stops moving. Selecting a docking station on the
map brings its entry to the top of the list.

## Reading an entry

| Line | Contents |
|------|----------|
| First | The docking station name |
| Second | The wider area the station sits in |
| Third | Distance, bikes available with e-bikes marked separately, and spaces free |

## Searching

1. Select the search field at the top of the panel.
2. Type any part of a docking station name.

The panel expands to full height when the search field is selected.

## Pinning and hiding

Swipe an entry in the list.

| Swipe action | Colour | Effect |
|--------------|--------|--------|
| Pin | Gold | The docking station is kept in Settings under Pinned docks |
| Hide | Grey | The docking station stops appearing in the list |

Pinned docking stations are listed in Settings, where they can also be
unpinned.

## Journeys

The Journeys tab lists past rides and totals for a signed-in account. It is
read from a cached copy, so it opens without waiting. Pull down to refresh.

## What the app will not do

| Task | Where it happens instead |
|------|--------------------------|
| Create an account | The operator's website |
| Buy or renew an access period | The operator's website |
| Change a payment card | The operator's website |
| Delete an account | The operator's website |
| Report a broken bike or dock | The operator's own channels |
| Reserve a bike | Not offered by the scheme |

Settings holds a **Manage account & payment** link that opens the operator's
website inside the app.
