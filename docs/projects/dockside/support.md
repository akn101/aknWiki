# Support

Support for the Dockside iPhone app.

| | |
|---|---|
| Publisher | akn Systems Ltd |
| Contact | kabir.a@akn.me.uk |
| Response time | None published |
| Channel | Email only. No phone number or postal address is published |

## Before writing

[Diagnostics](diagnostics.md) lists the conditions reported most often, with
resolutions. Most reports match an entry there.

## What akn can help with

| Subject | Handled |
|---------|---------|
| The app crashing, freezing, or drawing incorrectly | Yes |
| A docking station missing from the map | Yes |
| A count or distance that looks wrong in the app | Yes |
| A question about [Your information](privacy.md) | Yes |
| Signing in failing when the same details work on the operator's website | Yes |

## What akn cannot help with

akn does not operate the cycle hire scheme and has no access to any account
in it.

| Subject | Where to raise it |
|---------|-------------------|
| A charge on your card | The scheme operator |
| Buying, renewing, or refunding an access period | The scheme operator |
| A broken bike or docking point | The scheme operator |
| A release code that will not release a bike | The scheme operator |
| Your name, address, mobile number, or payment card | The scheme operator |
| Closing your cycle hire account | The scheme operator |

## Writing a useful report

Include the following.

| Item | Reason |
|------|--------|
| What you did, in order | Lets the fault be reproduced |
| What you expected, and what happened | Separates a fault from intended behaviour |
| The docking station name, if one is involved | Identifies the record |
| Your iPhone model and iOS version | Narrows the cause |
| The app version, from the App Store listing | Confirms whether it is already fixed |
| A screenshot | Faster than a description |

Do not include your cycle hire password. It is never needed and akn will
never ask for it.
