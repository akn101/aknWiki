# Diagnostics

Observed conditions and their resolutions.

## Reviewing

| Condition | Cause | Resolution |
|-----------|-------|------------|
| `No applicants found matching your filters.` | No record matches the block, position, or search term in force | Clear the search field and reset both filters |
| The dashboard lists no applicants at all | No applicants have been imported | Import a CSV file |
| An expected applicant is missing from the list | The record was absent from the imported file | Re-export from the form tool and import again |

## Importing

| Condition | Cause | Resolution |
|-----------|-------|------------|
| Imported records do not appear | The uploaded file was not a CSV export | Export the submissions as CSV and upload again |
| Applicants appear twice | The same file was imported more than once | Confirm the contents before repeating an import |

## Access

| Condition | Cause | Resolution |
|-----------|-------|------------|
| The dashboard cannot be reached | Access is limited to authorised staff | Request access from the site operator |

## Escalation

Conditions not resolved by the above should be reported to the site operator.
Include the URL, the browser, and the time the condition occurred.

Service availability is published at https://status.akn.me.uk.
