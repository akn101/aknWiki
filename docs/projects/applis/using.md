# Using the dashboard

The dashboard holds every applicant imported into Applis. Records arrive by
CSV upload rather than by direct application.

## End to end

1. Collect applications in a form tool.
2. Export the submissions from that tool as a CSV file.
3. Import the file into Applis.
4. Review the applicants, filtering by block or position.
5. Export the list as CSV or PDF.

## Importing applicants

1. Select **Upload Applications CSV**.
2. Choose the CSV file exported from the form tool.

The records in the file are added to the dashboard in one operation. No
per-applicant entry is required.

## Reviewing

The dashboard presents a central view of all submitted applicants. Each record
carries its submission details. Select a record to open the individual
applicant profile.

## Filtering and search

| Control | Effect |
|---------|--------|
| **All Blocks** | Limits the list to one cohort block or group assignment |
| **All Positions** | Limits the list to one role or programme |
| Search field | Locates a candidate by name or other identifier |

When no record matches the current selection, the dashboard displays
`No applicants found matching your filters.` This is the filter result, not a
fault.

## Exporting

| Format | Use |
|--------|-----|
| CSV | Further processing in spreadsheet software |
| PDF | Formatted reports for sharing or printing |

Both a shortlist and a full list can be exported.
