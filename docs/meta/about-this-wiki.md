# About

aknWiki is the documentation site for the products in the akn ecosystem. It is
published at https://docs.akn.me.uk and is readable by anyone.

## Coverage

| Subject | Included |
|---------|----------|
| What each product allows users to do | Yes |
| How to carry out each task in a product | Yes |
| What each product cannot do | Yes |
| Conditions users encounter, with resolutions | Yes |
| Which features require an account or an akn ID scope | Yes |
| Installation, configuration, and maintenance | No |
| Source code, internal design, and infrastructure | No |
| Live service availability | No |

Availability and incident history are published at https://status.akn.me.uk.

## Maintenance

Ahnaf Kabir writes and maintains every page. Readers cannot edit pages, comment
on them, or submit a correction through the site. Corrections are made by the
maintainer.

## Currency

Pages describe each product as it stood when the page was written. Pages carry
no revision date and the site holds no version history. Where a page and the
product disagree, the product is correct.
