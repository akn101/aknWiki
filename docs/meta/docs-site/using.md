# Finding pages

Navigation is by sidebar. The wiki has no search.

## The sidebar

The sidebar lists every section down the left of each page.

| Entry | Behaviour when selected |
|-------|------------------------|
| Section | Expands to list the products it holds |
| Product | Opens a contents page listing that product's pages |
| Page | Opens the page |

The current page is highlighted. Expanded sections stay expanded while moving
between pages.

On a narrow screen the sidebar is hidden. Open it from the navigation bar at
the top of the page.

## Finding a term

Search is not available. Use one of the following instead.

| Task | Method |
|------|--------|
| Find a product | Locate its section in the sidebar |
| Find a page within a product | Select the product to open its contents page |
| Find a heading on the open page | Use the contents list at the right of the page |
| Find a term on the open page | Use the browser find function, `Command-F` or `Control-F` |

The browser find function searches the open page only. It does not reach pages
that are not loaded.

## Moving between pages

Previous and next links appear at the foot of every page. They follow sidebar
order, stepping through the pages of the current product in the order the
product presents them. At the first and last page of a product they continue
into the neighbouring product.

| Element | Location | Purpose |
|---------|----------|---------|
| Breadcrumb trail | Top of the page | Names the section and product. Select an entry to move up |
| Contents list | Right of the page, on wide screens | Lists the headings on the page |
| Previous and next | Foot of the page | Moves to the adjacent page in sidebar order |
| Appearance control | Navigation bar | Switches between light and dark presentation |

## How sections are organised

Sections group products by kind. Sidebar order is fixed.

| Section | Holds |
|---------|-------|
| Core services | The portfolio site and the services around it |
| Platform | Sign-in and the shared services other products depend on |
| Projects | Charitable and professional projects |
| Gaodi | Brand and project management systems |
| Playground | Experiments and demonstrations |
| Meta | The wiki itself |

A section is a container. Selecting it expands the list rather than opening a
page.

## Reading a product's metadata table

Every product overview opens with an unlabelled two-column table carrying four
fields in the same order.

| Field | Meaning |
|-------|---------|
| URL | The address at which the product is reached |
| Description | What the product allows users to do, in one line |
| Access | Who may use the product, and what gates the restricted parts |
| Pricing | What a user pays to use the product |

### Access

Access answers two questions: who may reach the product, and which parts are
closed to them. An entry reading `Public` means no account is required. Where
part of a product is restricted, the entry names what unlocks it, such as an
akn ID scope. The page covering that restricted part names the scope required.

### Pricing

Pricing states what a user pays to use the product. Where a product carries no
charge the field reads `Free`.
