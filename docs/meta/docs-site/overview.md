# aknWiki

| | |
|---|---|
| URL | https://docs.akn.me.uk |
| Description | Documentation for the products in the akn ecosystem |
| Access | Public. No account required |
| Pricing | Free |

## Overview

aknWiki allows readers to browse documentation for every product in the akn
ecosystem. Each product occupies a section of its own, covering what the
product does, how to carry out each task, and what to do when something does
not work.

The site is read only for its audience. Pages are written and corrected by the
maintainer.

## Capabilities

| Capability | Availability |
|------------|--------------|
| Read any page | Any visitor |
| Browse products by section | Any visitor |
| Open a product's contents page | Any visitor |
| Move to the previous or next page | Any visitor |
| Jump to a heading on the current page | Any visitor |
| Move up a level from the breadcrumb trail | Any visitor |
| Switch between light and dark presentation | Any visitor |
| Link directly to a page or a heading | Any visitor |
| Search the wiki | Not available |
| Comment on a page | Not available |
| Edit a page as a reader | Not available |
| Submit a correction through the site | Not available |
| Accounts and sign-in | Not available |
| Notification when a page changes | Not available |
| Page history or earlier versions | Not available |
| Export a page as a file | Not available |

## Coverage

| Subject | Covered |
|---------|---------|
| What a product allows users to do | Yes |
| How to carry out each task in a product | Yes |
| What a product cannot do | Yes |
| Conditions users encounter, with resolutions | Yes |
| Which features require an account or an akn ID scope | Yes |
| Installation, configuration, and maintenance | No |
| Source code and internal design | No |
| Live service availability | No |

Service availability and incident history are published at
https://status.akn.me.uk.

## Reading the wiki

Every product section opens with an overview carrying the same four metadata
fields, followed by a capability table. Task pages come next, and a diagnostics
page last where the product has one.
