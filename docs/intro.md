# aknWiki

aknWiki documents the services and projects built and maintained by
[Ahnaf Kabir](https://akn.me.uk). Each product has its own section covering what
it does, how to use it, and what to do when something does not work.

Documentation here is written for the people who use these products. It
describes what a user sees and does. It does not cover installation,
configuration, or maintenance.

## Using this wiki

Products are documented as sections rather than single pages. Each section
opens with an overview carrying a metadata table, then splits into pages by
task.

| Field | Meaning |
|-------|---------|
| URL | Where the product is reached |
| Description | What the product allows users to do |
| Access | Who can use it, and which parts are restricted |
| Pricing | What it costs to use |

Capability tables list what a product does not do alongside what it does. Rows
marked `Not available` are accurate rather than pending.

Diagnostics pages list conditions users encounter, with causes and resolutions.

## Access

Some products restrict features by akn ID scope. Where a page states that a
feature is restricted, an account holding the relevant scope is required. The
aknID section covers how scopes work and how to request one.

## Languages
