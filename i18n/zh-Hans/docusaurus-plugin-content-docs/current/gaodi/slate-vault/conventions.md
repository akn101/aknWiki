# 约定

知识库的命名与元数据规则。本页所有示例均使用虚构名称。

## 文件夹名称

| 文件夹 | 规则 | 示例 |
|--------|---------|---------|
| 项目 | 英文产品名称小写，单词之间用连字符连接，然后加项目编号 | `example-camera-12` |
| 项目，名称仅有中文时 | `project-` 加项目编号 | `project-12` |
| 代次 | `gen-` 加代次编号 | `gen-1` |
| 品牌 | 品牌名称小写，单词之间用连字符连接 | `example-brand` |

项目编号是文件夹名称的一部分。因此两个同名产品各自保留独立的文件夹。

## 文件名称

| 文件 | 规则 | 示例 |
|------|---------|---------|
| Slate 撰写的文档 | 标题小写，单词之间用连字符连接，然后加 `-v` 与版本号 | `example-camera-specification-v3.md` |
| 项目记录 | 固定名称，不带版本号 | `project.md` |
| 上传的原始文件 | 提供时的原名，并加上 `-v1` | `example-returns-v1.xlsx` |
| 上传文档的文本 | 上传文件名，然后加 `.extracted.md` | `example-returns-v1.xlsx.extracted.md` |
| 冲突后保留的版本 | 文档名称，然后加 `.conflict-` 与一段短代码 | `spec-v3.conflict-a1b2c3d.md` |

版本号从 1 开始递增。每个新版本都是一个新文件。Slate 从不覆盖带版本号的文档。

中文文件名在各处均受支持。

## 元数据

Slate 撰写的每一份 Markdown 文档都以一个元数据块开头。数据文件和图片不带该块。

```text
---
project: example-camera-12
generation: 1
stage: voc
type: voc_report
version: 2
date: '2026-07-24'
source_job: 481
source_thread: null
---
```

| 字段 | 取值 |
|-------|-------|
| `project` | 项目文件夹名称 |
| `generation` | 代次编号。上传文件为空 |
| `stage` | 阶段名称。上传文件为空 |
| `type` | 文档类型。见下表 |
| `version` | 版本号，与文件名一致 |
| `date` | 文档撰写日期 |
| `source_job` | 产出该文档的 Slate 任务。上传文件与对话编辑为空 |
| `source_thread` | 产出该文档的对话。其他情况为空 |

另有两个字段在适用时出现。

| 字段 | 取值 |
|-------|-------|
| `change_note` | 修订原因。通过对话编辑文档时添加 |
| `sources` | 文档使用的编号引用，与正文中的来源列表一致 |

## 文档类型

| 类型 | 含义 |
|------|---------|
| `specification` | 产品规格书 |
| `market_report` | 竞品与市场分析 |
| `voc_report` | 客户评论分析 |
| `dataset` | 表格数据，例如竞品或退货导出 |
| `copy` | Listing 文案 |
| `marketing_image` | 生成的产品图或场景图 |
| `manual` | 产品手册或说明书 |
| `brand_asset` | 品牌套件素材 |
| `positioning` | 产品线定位 |
| `profit_model` | 成本与利润模型 |
| `factory_brief` | 给工厂的说明 |
| `misc` | 以上未涵盖的内容，包括提取出的文本 |
| `ops_report` | 保留。没有阶段写入此类型 |

## 项目记录

`project.md` 保存一个项目的设置。这些设置发生变化时，Slate 会重写它。

| 字段 | 取值 |
|-------|-------|
| `slug` | 项目文件夹名称 |
| `name` | 录入的产品名称 |
| `name_en` | 英文产品名称。未设置时为空 |
| `sku` | 型号。未设置时为空 |
| `category` | 产品类目 |

记录正文包含两个可选章节。

| 章节 | 用途 |
|---------|---------|
| `## Description` | 产品是什么，面向哪些市场 |
| `## Notes for AI` | Slate 对该项目每一份文档都会应用的常驻指令 |

## 新增条目

### 新建项目

1. 在 Slate 中创建项目。
2. 填写名称、英文名称、型号和产品类目。

项目文件夹与项目记录会自动写入。请勿手工创建项目文件夹。

### 新建文档

1. 在 Slate 中运行该阶段，或在对话中提出修改要求。
2. 等待运行结束。

文档会以下一个版本号写入对应的阶段文件夹。

### 新增上传

1. 在 Slate 中选择上传控件。
2. 选择文件。
3. 确认或更正 Slate 建议的文档类型。

Slate 会根据文件名、文件扩展名和文件内的文本建议类型。已确认的类型不会再被更改。

### 新建品牌套件

1. 在 `brands` 下创建一个文件夹。
2. 添加 `guidelines.md`，写入语气与文案规则。
3. 添加 `palette.yml`，写入按用途划分的颜色。
4. 添加 `refs` 文件夹，并把参考图放入其中。

品牌套件由人工添加。没有阶段写入 `brands`。

## 在 Obsidian 中编辑

| 编辑操作 | 是否支持 |
|------|-----------|
| 修改文档文本 | 支持 |
| 添加自定义元数据字段，例如标签或审核人 | 支持 |
| 重命名、编辑或删除 `uploads` 中的文件 | 支持 |
| 添加或编辑品牌套件 | 支持 |
| 重命名或重新编号 Slate 撰写的文档 | 不支持。该文档会从 Slate 中消失，其引用也会失效 |
| 重命名任何标准元数据字段 | 不支持。该文档会从筛选列表中消失 |
| 在 Slate 正在撰写某文档新版本时编辑该文档 | 不支持。两个版本都会保留，需要人工合并 |
| 删除配套文本文件 | 允许。下一次读取时会重新生成 |

文本归操作员所有。文件名、标准元数据字段和版本号归 Slate 所有。

Slate 每五分钟重新读取一次知识库。
