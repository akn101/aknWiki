# Slate 知识库

| | |
|---|---|
| 说明 | 文档库，存放 Slate 产出的每个文件以及操作员上传的每个文件 |
| 访问 | 受限。内容属于商业与内部资料。上传的原始文件可能包含客户数据，不得对外发布 |
| 定价 | 随 Slate 一并提供 |

## 概览

Slate 知识库让用户可以阅读、搜索并编辑一个项目产出的每一份文档，这些文档以一个普通文件夹的形式保存。系统提供访问控制，可由组织设置。

知识库有两个写入方。Slate 把每个阶段的产出和每次上传都记录为一个新文件。操作员在 Obsidian 中打开同一个文件夹，直接编辑其中的文本。

## 知识库存放的内容

| 文件夹 | 存放内容 |
|--------|------|
| `brands` | 品牌套件：语气、配色、参考图 |
| `projects` | 每个项目一个条目，存放该项目的上传文件与阶段产出 |

每一份文档都是 Markdown、纯数据文件或图片文件。打开任何一份文档都不需要 Slate。

## 功能

| 功能 | 可用性 |
|------------|--------------|
| 在一处阅读一个项目的全部文档 | 拥有知识库访问权限的操作员 |
| 在 Obsidian 中编辑文档文本 | 拥有知识库访问权限的操作员 |
| 为文档添加自定义元数据字段 | 拥有知识库访问权限的操作员 |
| 重命名、编辑或删除上传的原始文件 | 拥有知识库访问权限的操作员 |
| 手工添加品牌套件 | 拥有知识库访问权限的操作员 |
| 保留文档的每一个早期版本 | 自动 |
| 记录文档的修改人与修改时间 | 自动 |
| 通过重命名文件添加新版本 | 不可用 |
| 重命名 Slate 撰写的文档 | 不可用 |
| 把 Slate 撰写的文档移动到其他文件夹 | 不可用 |
| 两人同时编辑同一份文档 | 不可用 |

## 版本历史

| 属性 | 详情 |
|----------|--------|
| 新版本 | 以下一个版本号写为新文件 |
| 早期版本 | 保留。Slate 从不覆盖带版本号的文档 |
| 项目记录 | 原地重写。它不带版本号 |
| 作者信息 | 每次变更都会记录修改人与修改时间 |
| 删除 | 删除文件后，Slate 在下一次读取时将其移除 |

## 保密

| 属性 | 详情 |
|----------|--------|
| 上传的原始文件 | 按提供时的原样存储，包括其中的任何个人数据 |
| Slate 产出的报告 | 基于匿名化数据撰写。评论者姓名与主页不会带入 |
| 分发 | 仅限内部。知识库不得放置在公开主机上 |
