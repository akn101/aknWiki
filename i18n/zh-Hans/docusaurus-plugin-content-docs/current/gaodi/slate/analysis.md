# 分析阶段

分析阶段判断一个产品是否值得进入市场。它带有八个调研模块，产出机会评分、利润
模型与进入建议。后续阶段会读取它的结论。

用阶段顶部的标签在各模块之间切换。

| 标签 | 模块 | 回答的问题 |
|-----|--------|---------|
| **01 调研概览** | 调研概览 | 机会有多好，以及评估中有多少是有数据支撑的 |
| **02 竞品池** | 竞品池 | 产品在和谁竞争，以及这个池子够不够深 |
| **03 市场规模** | 市场规模 | 类目有多大、集中度如何、正朝哪个方向走 |
| **04 关键词** | 关键词 | 哪些搜索词承载着需求 |
| **05 VOC** | 客户之声 | 客户在抱怨什么。在客户之声阶段产出 |
| **06 利润模型** | 利润模型 | 在各个价格与成本下，单件能赚多少 |
| **07 风险** | 风险清单 | 还有哪些没有核实 |
| **08 结论** | 进入建议 | 推进、有条件推进还是不推进，以及是什么在拖住它 |

## Slate 如何报告缺失的数字

以下规则适用于每一个模块。

| 显示 | 含义 |
|---------|---------|
| 斜纹条配 **未测量** | 该数字没有数据。这不是数值为零 |
| `0` | 实测得到的零 |
| 琥珀色的 **暂定** | 数字本身正确，但评估框架中有数据的部分不到一半 |
| **未验证** | 一个数据截至 2024 年、尚未重新核实的费率或关税常数 |
| **运营输入** | 你填入的数值，按你填写的原样使用 |
| **未计入** | 一项未纳入测算的费用。这不代表该费用为零 |

缺失的子指标绝不会被记为零分。它会从计算中剔除，剩余的权重重新归一。

## 01 调研概览

调研概览呈现满分 100 的机会评分、它的四个维度、框架覆盖率与证据置信度。

| 维度 | 权重 | 什么情况下分高 |
|-----------|--------|-----------------|
| **市场需求** | 30% | 销售规模、搜索需求、趋势与广度都很强 |
| **竞争机会** | 25% | 市场容易进入。竞争越强分越低，而不是越高 |
| **产品匹配度** | 20% | 现有规格已经满足市场的诉求 |
| **利润潜力** | 25% | 利润、盈亏平衡 ACOS、悲观情景与价格缓冲都站得住 |

**证据置信度** 单独呈现，不计入评分。它说明结论所依赖的信息中有多少是被可靠数
据或人工验证支撑的。它不说明这个答案有多大概率正确。

**下一步最优动作** 列出当前还未满足的条件。每一条都带有一个 **去处理** 链接，
指向能满足它的模块。

## 02 竞品池

选择 **采集清单** 从网络与市场采集相似产品。无需任何上传。

Slate 会报告有多少条是真实商品页。搜索页、类目落地页与无价格页面会被标记为
**非商品页**，并从覆盖计数中排除。要精准加入某个竞品，把它的链接粘贴到阶段对
话中。

### 分层

给每个竞品分层。Slate 仅凭价格给出分层建议，并把该建议标记出来供你确认。价格
无法把直接竞品和替代品区分开。

| 分层 | 目标深度 |
|------|--------------|
| **直接竞品** | 10 到 15 |
| **标杆竞品** | 5 |
| **替代品** | 3 到 5 |

覆盖条会把差距完整说明，例如直接竞品 6 条、目标 10 到 15，还差 4 条。

### 输出

| 操作 | 产出 |
|--------|----------|
| **标题+链接 (Markdown)** | 已选行的清单 |
| **标题+链接 (文本)** | 同样的清单，纯文本格式 |
| **Excel 数据集 (.xlsx)** | 已选行的表格 |
| **增强数据集** | 带规格提取的表格。作为后台任务运行 |
| **生成报告** | 一份写入项目文件的差距报告 |

## 03 市场规模

尚未做过调研的项目会显示一次运行能产出什么，并提供 **开始市场调研**。选择它，
待任务结束后再选择 **刷新**。在工作真正完成之前，页面绝不会宣称已完成。

| 小节 | 内容 |
|---------|----------|
| 类目节点判定 | 调研最终认定的类目节点，以及考虑过的候选节点 |
| 市场规模、集中度与趋势 | 实测数字，每一项都带来源与可靠性标注 |
| 抽样校验 | 可信度分级背后的核对过程 |
| 关键结论 | 从上述内容得出的结论 |

节点判定有两种措辞，二者强度并不相同。多个高销量竞品集中在同一节点，意味着该
节点就是真实类目。竞品分散在多个节点，则意味着 Slate 取了最集中的那个节点，这
是较弱的判定，值得人工复核。

| 可靠性 | 如何对待 |
|-------------|----------|
| **高** | 可直接使用。仍值得对照抽样校验确认 |
| **中** | 属于估算值。请确认口径与数量级 |
| **低** | 仅供参考。任何结论依赖它之前，必须人工验证 |

完整报告及其原始数据表会写入项目文件。页面上只放关键结论，以及一个写着
**查看完整报告** 的链接。数字绝不跨站点比较。

一次运行如果结束时一个数字都没取到，会明说这一点并指出可能的原因。此时显示空
白，而不是编造数字。

## 04 关键词

由与 **03 市场规模** 相同的那次市场调研填充。它列出主要搜索词及其月搜索量，以
及建立在这些词之上的需求与趋势数字。

这些词决定了哪些竞品算数、哪个类目才是真实类目，也是广告与文案工作的起点。

## 05 VOC

评价主题与退货风险在客户之声阶段产出。打开客户之声阶段上传评论与退货导出表，
或者阅读已经在那里产出的产品问题分析报告。

## 06 利润模型

这里的每一个数字都是确定性计算得出的。不涉及任何模型。

### 价格带

采集到相似产品后，价格带会自动出现。每个价格带带有评论加权密度及其代表商品。
选择 **选用此价格带** 即可应用。

### 成本情景

1. 填写单位成本的下限与上限。
2. 调整售价与转化率。

Slate 会在 **悲观**、**基准** 与 **乐观** 三种情景下报告单位成本、利润、盈亏平
衡 ACOS 与可承受 CPC。成本高于售价时，卡片显示 **不可投放**，而不是打印一个负
数出价。

### 费用输入

费用字段留空即使用 2024 年常数，这些常数标注为 **未验证**。你填入的数值会按原
样使用，并在情景测算与报告中标注为 **运营输入**。

| 字段 | 涵盖 |
|-------|--------|
| **FBA 配送费（每件）** | 每件的履约成本 |
| **推荐费率（0-1）** | 平台推荐佣金 |
| **退货计提率（0-1）** | 为退货预留的计提 |
| **优惠券（每件）** | 每件的优惠券成本 |

每件成本明细会写明每一行的来源。未纳入的费用显示 **未计入**。

### 价格点报告

选择 **一键价格点报告**，把当前的售价与成本情景写入项目文件，形成一份带引用的
利润模型报告。

## 07 风险

这里列出八项常设风险，每一项都说明要核对什么。

| 状态 | 含义 |
|--------|---------|
| **待确认** | 还没看过 |
| **确认存在** | 风险真实存在且尚未解决 |
| **已缓解** | 已经处理 |
| **接受风险** | 真实存在，且接受现状 |

把证据或决定写在备注字段里。未确认的风险绝不会阻断结论。它只会把结论限制在
**有条件推进**，并在其中写明。

## 08 结论

结论受机会评分、证据置信度、框架覆盖率与风险确认共同约束。证据补齐后会自动重
算。

| 判定 | 含义 |
|---------|---------|
| **推进** | 没有未满足的条件 |
| **有条件推进** | 可以推进，但须满足所列条件 |
| **不推进** | 不要推进 |

**未满足的条件** 写明判定没有成为干净的 **推进** 的每一条原因。修改证据后选择
**重新计算**，选择 **导出结论备忘** 可把结论写入项目文件。
