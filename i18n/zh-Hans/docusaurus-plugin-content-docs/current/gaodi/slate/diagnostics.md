# 问题排查

已知情形及其处理方式。

## 登录

| 情形 | 原因 | 处理方式 |
|-----------|-------|------------|
| **登录失败，请检查邮箱和密码** | 邮箱或密码不正确 | 重新输入两者。如果账户是刚创建的，请询问管理员 |
| 用过一段时间后又出现登录界面 | 会话已超过 7 天 | 重新登录 |
| 没有 **手机验证码登录** 标签页 | 该组织未启用验证码登录 | 使用密码或企业微信登录 |
| **该手机号尚未关联账号，请联系管理员** | 该手机号未绑定到任何账户 | 先用密码登录，再在 **设置** 中的 **个人资料** 里绑定手机号 |
| **验证码无效或已过期，请重新获取** | 验证码输错，或已超过 5 分钟 | 选择 **重新发送** |
| **操作过于频繁，请稍后再试** | 反复请求验证码 | 稍等一会儿，然后只请求一次验证码 |
| **短信服务暂时不可用，请改用密码登录** | 验证码下发不可用 | 使用密码登录 |
| **该手机号已绑定到其他账号** | 另一个账户持有该手机号 | 换一个手机号，或请管理员解绑 |
| **企业微信登录不可用，请稍后再试或联系管理员** | 无法访问企业微信登录 | 使用密码登录 |

## 项目

| 情形 | 原因 | 处理方式 |
|-----------|-------|------------|
| **请输入项目名称** | **名称** 字段为空 | 填写产品名称 |
| **请输入产品类目** | 既没有类目名称，也没有类目链接 | 填写类目，或粘贴一条亚马逊类目链接 |
| 粘贴链接后类目仍为空 | 该链接不含 Slate 能识别的类目 | 手动填写类目 |
| **部分文件上传失败** | 一个或多个初始文件没有上传成功 | 项目仍已创建。请从阶段文件栏重新上传这些文件 |
| 项目信息表单无法编辑 | 该账户不是项目管理员 | 请项目管理员来改 |
| **协作范围** 面板为只读 | 该账户不是项目管理员 | 请项目管理员更改可见范围 |
| **代次** 列表只有一条 | 界面上暂不支持开启新的代次 | 在现有代次中继续 |

## 阶段对话

| 情形 | 原因 | 处理方式 |
|-----------|-------|------------|
| **生成失败** | 模型调用没有完成 | 选择 **重试** |
| 回复中途停止并被标记为已中断 | 选择了 **停止**，或者连接断开 | 部分回复会延续到下一轮。发送下一条消息即可 |
| **最多可附加 10 个文件** | 已达到附件数量上限 | 先发送这条消息，下一轮再附加其余文件 |
| **附件上传失败，请重试** | 上传没有完成 | 重新附加该文件。确认它小于 25 MB |
| **需先附加项目才能拖放上传文件** | 快速对话没有附加项目 | 选择 **选择项目** |
| **最多可调用 10 个技能手册** | 已达到技能数量上限 | 移除一个技能，或把请求拆到多轮 |
| **未找到匹配的技能手册** | 没有技能名称与所输入的内容匹配 | 清掉 `/` 后面的文字，查看完整列表 |
| **该阶段的自动化尚未上线** | 该阶段是复盘，不可用 | 使用其余五个阶段 |
| **此项目暂无代次** | 该项目还没有代次 | 询问管理员 |

## 运行阶段操作

| 情形 | 原因 | 处理方式 |
|-----------|-------|------------|
| **已由他人启动** | 同一个操作已经在运行 | 在 **任务队列** 中查看。不要再启动第二次 |
| 某个次要操作被禁用 | 它在本代次的前提尚未满足 | 把鼠标停在按钮上查看缺什么，然后在本代次中产出它。上一代次的材料绝不会被复用 |
| 任务失败并列出错误 | 流水线中途停止 | 选择 **重试**。它会从上一个检查点继续 |
| 操作按钮不显示 | 该账户不持有操作员项目角色 | 请项目管理员授予操作员角色 |

## 调研与分析

| 情形 | 原因 | 处理方式 |
|-----------|-------|------------|
| 某个数字显示斜纹条与 **未测量** | 该数字没有取到数据 | 运行提供该数据的模块。空白不是数值为零 |
| **本次运行没有取得任何数据** | 市场调研跑完了，但数据源什么都没返回，通常是因为没有配置凭据 | 请管理员配置数据源，然后重新运行 |
| 评分被标注为 **暂定** | 评估框架中有数据的部分不到一半 | 补齐缺失的维度。数字本身正确，但还不是结论 |
| **待评估** | 没有任何维度有数据 | 在 **06 利润模型** 中填写价格与成本区间 |
| 某个成本情景显示 **不可投放** | 成本高于售价 | 降低成本或提高售价 |
| 某个竞品行显示 **未标价** | 该页面没有给出 Slate 能读取的价格 | Slate 宁可留空也不猜测。如有需要请手动填写价格 |
| 某一行被标记为 **非商品页** | 该链接是搜索页或类目页，或者没有价格 | 把单个商品的链接粘贴到阶段对话中 |
| 分层覆盖显示未达目标 | 已分层的竞品少于目标区间 | 再采集一些产品，或者给未分层的行分层 |
| 结论被限制在 **有条件推进** | 有一个或多个风险未确认，或者有条件未满足 | 阅读 **08 结论** 上的 **未满足的条件**，逐条处理 |
| 某项费用被标记为 **未验证** | 该数字是 2024 年常数，未按当年重新核实 | 在费用输入中填写你自己的数值 |
| VOC 报告中缺少退货率对比 | 没有填写任何退货率行 | 在客户之声阶段填写这些行，然后重新运行报告 |

## 文件

| 情形 | 原因 | 处理方式 |
|-----------|-------|------------|
| **此文件类型暂不支持预览** | Slate 无法渲染这种格式 | 选择 **下载**，在本地打开 |
| **无权访问此文件** | 该账户不是该项目的成员 | 请项目管理员把该账户加入项目 |
| 提示会话已过期 | 会话已超过 7 天 | 重新登录 |
| 表格显示的行数少于文件中的行数 | 读取上限为每个工作表 200 行、40 列 | 下载文件以完整阅读 |
| 模型没有使用某个上传的文件 | 该文件超过 25 MB，或者格式 Slate 无法读取 | 以 PDF、Excel、Word、CSV、Markdown 或纯文本提供其内容 |
| **仅支持 .xlsx 或 .csv 报表文件** | 报表解析拿到的是别的格式 | 把报告重新导出为 `.xlsx` 或 `.csv` |
| **未识别的报告类型** | 该文件不是亚马逊搜索词报告或业务报告 | 重新上传之前先核对导出内容 |
| 结果被标记为 **已截断** | 已达到行数上限 | 把报表拆开，分别解析每一部分 |
| **你对此项目为只读权限，无法发表评论。** | 该账户持有观察者项目角色 | 请项目管理员授予更高的角色 |

## 任务与审核

| 情形 | 原因 | 处理方式 |
|-----------|-------|------------|
| **加载失败，请重试** | 无法取得任务列表 | 选择 **重试** |
| **定时任务服务尚未上线** | 本环境未启用定时任务 | 询问管理员 |
| **该任务类型未注册** | 所选的周期性任务未启用 | 换一个任务类型 |
| 某项成本显示 **未计价** | 所用的模型未配置价格 | 把本页合计当作下限。这项工作并非免费 |
| 某项成本显示 **未调用模型** | 该任务没有使用模型 | 无需处理。成本确为零 |
| **此项已审核完成** | 另一位审核员先做了决定 | 重新加载收件箱 |
| 侧边栏没有 **审核收件箱** | 该账户持有操作员角色 | 请管理员授予审核员角色 |
| 无法创建或开关定时任务 | 该账户不是审核员或管理员 | 请审核员或管理员处理 |

## 管理

| 情形 | 原因 | 处理方式 |
|-----------|-------|------------|
| **该邮箱已被注册** | 已有账户持有该邮箱 | 启用现有账户，不要另建新账户 |
| **无法停用或降级自己的账户** | 该操作指向当前登录的账户 | 请另一位管理员来改 |
| 临时密码丢失 | 密码只显示一次，且不以可读形式存储 | 询问管理员。该密码无法找回 |
| **仍有项目关联此套件** | 使用中的品牌套件无法删除 | 把这些项目改绑到别处，或者停用该套件 |
| 技能导入被拒绝 | 文件超过 500 KB，不是 `.md` 或 `.zip`，缺少名称或分类，或者写了不存在的工具名 | 更正文件后重新导入 |
| **设置** 只显示一个标签页 | 该账户只能访问那一个标签页 | 无需处理。其他标签页需要更高的角色 |
| 某个连接器显示 **未配置** | 该数据源没有设置密钥 | 由管理员在 Slate 之外配置。密钥绝不在浏览器中输入 |

## 报告问题

在任意页面的右下角选择 **反馈**。

1. 选择 **类型**：**问题**、**建议** 或 **疑问**。
2. 选择 **紧急程度**。
3. 描述你在做什么、发生了什么，以及你期望发生什么。
4. 附上截图。截图可以从项目页面附加。
5. 选择 **提交**。

Slate 会把页面、项目、对话与版本随报告一起记录下来。回复出现在 **我的反馈**
下。Slate 最近的改动列在 **更新日志** 下。
