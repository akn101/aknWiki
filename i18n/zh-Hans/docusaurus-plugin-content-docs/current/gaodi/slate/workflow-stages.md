# 工作流阶段

一个代次按顺序走完六个阶段。阶段可以随时回头重做。进入某个阶段并不要求上一个
阶段已经完成。

从项目页面的阶段进度列表打开一个阶段，或者从任意阶段页面顶部的编号圆圈打开。

## 六个阶段

| 序号 | 阶段 | 该阶段做什么 | 主要操作 |
|--------|-------|--------------------|----------------|
| 1 | **设计** | 从消费者意图与竞争产品出发，产出并修订产品规格书 | **开始分析** |
| 2 | **分析** | 发现竞品，对比价格与规格，并报告与当前规格之间的差距 | **开始竞品分析** |
| 3 | **客户之声** | 从评论与退货中聚类客户痛点，产出一份报告和一份工厂数据集 | **提取痛点** |
| 4 | **迭代** | 综合分析结果、客户之声发现与备注，产出改进后的规格版本 | **生成新版规格** |
| 5 | **生成** | 产出符合品牌指南的 Listing 文案与图片 | **生成** |
| 6 | **复盘** | 不可用。该阶段可以打开，但操作位置显示 **即将推出** | 无 |

分析阶段本身带有八个调研模块。参见
[分析阶段](analysis.md)。

## 阶段页面

| 区域 | 内容 |
|--------|----------|
| 阶段页头 | 六个编号阶段。当前阶段高亮显示 |
| 欢迎文字 | 该阶段做什么，以及 **随时可以回来** 这句提示 |
| 文件栏 | 一个上传区域，以及一个按本阶段文件类型过滤的文件查找 |
| 对话 | 当前对话的消息 |
| 操作栏 | 主要操作，以及本阶段的次要操作 |
| 对话切换 | 本阶段的每一个对话，外加 **新建对话** |

## 进行对话

1. 输入消息。按 `Enter` 发送，按 `Shift+Enter` 换行。
2. 回复在生成过程中逐字流入对话。
3. 选择 **停止** 可以中断回复。

被中断的回复会在对话中标记出来，其内容会延续到下一轮。

| 功能 | 说明 |
|---------|--------|
| 项目上下文 | 项目记录、当前规格书、最近文件与 **给 AI 的备注** 会在每一轮提供给模型 |
| 模型 | 从 **模型** 中选择。保持 **默认（按阶段路由）** 即使用该阶段自己的模型 |
| 处理步骤 | 模型使用的每个工具都显示为一个标签：**搜索中**、**读取网页**、**保存文件**、**生成图片** 等 |
| 来源 | 被引用的网页列在回复下方的 **来源** 中 |
| 重试 | 失败后 **重试** 会重新发送上一条消息 |

### 附件

1. 选择 **附加**，或把文件拖到对话上。
2. 文件会列在输入框上方。
3. 发送消息。

每轮最多附加十个文件。单个文件不超过 25 MB。Slate 可读取 PDF、Excel、Word、
CSV、Markdown 与纯文本文件，图片则直接读取。

### 技能

技能是模型可以加载的书面打法手册：关键词调研、FBA 费用测算、竞品分析等。

1. 在输入框中输入 `/`。
2. 用方向键在列表中移动。
3. 按 `Enter` 把该技能加入本轮。

每轮最多调用十个技能。Slate 也会在无需你要求的情况下加载与当前阶段相关的技能。
按 `Escape` 关闭选择器。

### 对话

一个阶段可以有任意数量的对话。用第二个对话来推进另一条独立的调查线索。

| 操作 | 效果 |
|--------|--------|
| **新建对话** | 在本阶段开启一个空对话 |
| **重命名对话** | 重命名该对话。输入名称后按 `Enter` |
| **归档对话** | 把该对话从最近列表中隐藏 |
| **恢复** | 把已归档的对话恢复到活动列表 |

## 运行阶段操作

选择对话右下角的主要操作。Slate 会启动一个任务，在页面内显示其进度，并把输出
写入项目文件。

| 情形 | 行为 |
|-----------|-----------|
| 任务运行中 | 进度显示在页面内，并带有一个 **在任务队列查看** 的链接 |
| 任务完成 | 文件列表自动刷新 |
| 任务失败 | 显示失败信息与原因。重试会从上一个检查点继续 |
| 已有其他成员启动 | 按钮提示 **已由他人启动**，且不会启动任何任务 |

运行阶段操作需要操作员项目角色及以上。

### 次要操作

有些阶段在主要操作旁还带有额外操作。

| 阶段 | 次要操作 | 前提 |
|-------|-----------------|----------|
| 设计 | **定位方案** | 本代次已有客户之声结论 |
| 分析 | **市场报告** | 无 |
| 客户之声 | **综合研判** | 本代次已有产品问题分析报告 |
| 生成 | **生成说明书** | 本代次已有产品规格书 |
| 生成 | **合规检查** | 无 |

前提未满足的次要操作会被禁用。把鼠标停在按钮上可以看到缺什么。上一代次的材料
绝不会被复用。

## 客户之声阶段

客户之声阶段把评论导出表与退货导出表转成一份产品问题分析报告，以及一份工厂可
以直接执行的数据集。

1. 通过文件栏上传评论导出表与退货导出表。
2. 选择 **提取痛点**。

Slate 会自行找到已上传的文件。它产出一份确定性的报告，包含严重程度分级、每个
问题的证据条数，以及从每一条证据回溯到其文件、工作表、行号与 ASIN 的链路。此
外还会同时产出一份由模型撰写的摘要。

| 属性 | 说明 |
|----------|--------|
| 个人数据 | 评论者姓名与主页地址在入库时哈希处理。头像图片被丢弃 |
| 证据 | 每个问题最多三条客户原话，每个品类最多八个问题。被略去的数量会写在表格下方 |
| 退货原因 | 按品类归并为前六项的表格。含义不明的原因代码单独列出，由你归类 |
| 承运与仓储损坏 | 单独计为一类，绝不计入产品缺陷 |

### 类目退货率对比

退货导出表不含销量分母，类目均值又属于外部市场知识。因此这两个退货率都必须由
人工填写。

1. 在客户之声阶段打开退货率面板。
2. 选择 **添加一行**。
3. 填写品类、站点、类目退货率与我们自己的退货率。
4. 选择 **保存**。

保存时 Slate 会算出百分点差、倍数与压力判断。你填入的数字会进入工厂阅读的报告，
并在全文中标注为 **未验证**。留空时，报告中根本不会出现对比小节。

## 生成阶段

生成阶段根据最新规格书产出 Listing 文案与产品图片。选择 **生成 v1** 产出第一版
草稿。

| 功能 | 说明 |
|---------|--------|
| 字段 | 标题、**关于此商品** 要点、**商品描述** 与 **后台搜索词** |
| 计数 | 每个字段显示已用的字符数或字节数，以及其上限 |
| 合规 | 每个字段带有一个标记，列出其错误与提醒。选择该标记可查看详情 |
| 预览 | **桌面** 与 **手机**。手机预览会标出标题被截断的位置 |
| 修订标记 | 与上一版的逐字对比 |
| 锁定 | 已锁定的字段在重新生成草稿时会被跳过 |
| **告诉 AI** | 把针对某一个字段的修改指令发送到对话中 |
| **送审** | 把某一个字段发送给选定的审核人 |
| 图片 | 七种用途：**主图**、**场景图**、**信息图**、**尺寸图**、**材质图**、**对比图**、**副图** |
| 图片导出 | **下载全部图片 ZIP** |
| 版本 | **保存为新版本**。较早的版本仍可阅读 |

文案旁显示的价格来自分析阶段的价格带，并带有 **未验证** 的费用标注。

## 迭代阶段

迭代阶段把分析结果、客户之声发现与你的备注综合成一个新的规格版本。

| 面板 | 内容 |
|-------|----------|
| **输出版本** | 本代次产出的每一个规格版本 |
| **最终文件** | 本代次中被标记为最终版的文件 |
