# 文件

每个阶段产出的文件，以及你上传的每个文件，都保存在项目的知识库中。Slate 读取
这个知识库，知识库在 Slate 之外也可以读取。知识库本身参见 Slate Vault。

## 文件类型

每个文件带有一个类型。类型决定了它出现在哪个阶段的文件查找中，以及归入哪个文
件夹。

| 类型 | 存放 |
|------|------|
| **规格书** | 产品规格书 |
| **市场报告** | 市场调研与差距报告 |
| **VOC 报告** | 痛点报告与评论摘要 |
| **数据集** | 表格与归一化后的报告数据 |
| **文案** | Listing 文案版本 |
| **营销图片** | 生成的产品图片 |
| **产品手册** | 产品手册 |
| **品牌资产** | 品牌指南文档与参考图片 |
| **定位** | 定位分析 |
| **利润模型** | 价格点与利润报告 |
| **工厂简报** | 写给工厂的发现 |
| **运营报告** | 定时任务产出的报告 |
| **其他** | 其余任何内容 |

## 上传

文件可以从任意阶段页面的文件栏上传，也可以从项目创建表单上传，或者拖到对话上。

1. 把文件拖到上传区域，或选择该区域来挑选文件。
2. Slate 识别每个文件的类型并显示出来。
3. 确认或更正类型。

| 限制 | 说明 |
|------------|--------|
| 单个文件最大 | 25 MB |
| 可读取格式 | PDF、Excel、Word、CSV、Markdown、纯文本与图片 |
| PDF 读取 | 前 50 页 |
| 表格读取 | 每个工作表的前 200 行与 40 列 |
| 文本读取 | 前 200,000 个字符 |

超过上限的文件，或 Slate 无法读取其格式的文件，仍会被存储。只是模型读不到它的
内容。截断情况会在文件上说明。

## 查找文件

### 从阶段查找

每个阶段页面上的文件栏都带有一个已按该阶段文件类型预先过滤的查找。把 **类型**
放宽，或按名称搜索。选中一个文件即把它作为输入附加到该阶段。

### 从侧边栏查找

展开一个项目会显示 **市场报告**、**规格** 与 **资产**。每一项都会打开一个文件
夹视图。

| 控件 | 效果 |
|---------|--------|
| 类型筛选 | 把列表限定到一个文件类型 |
| 代次筛选 | 把列表限定到一个代次 |
| **搜索文件** | 匹配文件名 |
| **列表** 与 **网格** | 切换布局 |

## 阅读文件

打开一个文件，在其详细信息旁阅读内容。

| 信息 | 含义 |
|--------|---------|
| **类型** | 文件类型 |
| **版本** | 该文件的版本号 |
| **阶段** | 产出它的阶段 |
| **代次** | 它所属的代次 |
| **Git 提交** | 它进入时记录的变更 |
| **创建时间** 与 **更新时间** | 时间戳 |
| **路径** | 它在知识库中的位置 |
| **文档属性** | 写入文件的任何元数据字段 |

Markdown 文件渲染为带格式的文本。表格与 CSV 文件渲染为表格，可用 **原始** 与
**表格** 切换视图。较长的表格显示开头若干行，并说明显示了多少行。Slate 无法渲
染的文件类型会显示 **此文件类型暂不支持预览**。

选择 **下载** 保存原始文件。

## 评论

评论保存模型留下的审阅备注，以及你的团队留下的回复。

1. 打开文件。
2. 输入评论。
3. 选择 **发表**。

评论可以锚定到文档中的某个位置。模型撰写的备注会署上撰写它的模型名。持有观察
者项目角色的成员可以阅读评论，但不能发表评论。

## 版本

Slate 写入新版本，而不是覆盖文件。较早的版本仍可阅读。版本号会在每个列表中显
示在文件旁。

## 解析亚马逊报表

报表解析把亚马逊搜索词报告或业务报告转成结构化数据集，每一行都可追溯回它的来
源行。

1. 打开项目的 **运营**。
2. 选择 **选择报表**。
3. 选择 **开始解析**。

| 限制 | 说明 |
|------------|--------|
| 格式 | `.xlsx` 与 `.csv` |
| 最大大小 | 25 MB |
| 行数上限 | 达到上限的文件会标记 **已截断** |
| 权限 | 操作员项目角色及以上 |

结果会写明识别出的报告类型、保留的行数、跳过的行数与写入的数据集。无法识别的
报告显示 **未识别的报告类型**。选择 **查看数据集** 阅读输出。

## 保密

上传的评论与退货导出表按原样带有客户数据。Slate 从中产出的报告是基于匿名化数
据撰写的：评论者姓名与主页地址在入库时哈希处理，头像图片被丢弃。上传的原件保
留其原有内容。
