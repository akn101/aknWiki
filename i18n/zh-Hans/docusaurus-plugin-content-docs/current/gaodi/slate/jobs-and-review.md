# 任务与审核

耗时较长的工作以任务的形式运行。需要人工批准的工作在审核收件箱中等待。

## 任务队列

在侧边栏打开 **任务队列**。队列是共享的：每位成员都能看到所有任务，并看到启动
它的成员署名。

| 列 | 内容 |
|--------|----------|
| **类型** | 该任务做什么，例如 **痛点提取** 或 **市场报告** |
| **项目** | 该任务所属的项目 |
| **创建时间** | 它是什么时候启动的 |
| 状态 | **等待中**、**运行中**、**已完成** 或 **失败** |

| 控件 | 效果 |
|---------|--------|
| **全部** 与 **我的** | 显示所有任务，或只显示你自己的任务 |
| **刷新** | 重新加载列表 |
| **自动刷新** | 持续重新加载列表 |
| **重试** | 从上一个检查点重新启动失败的任务 |
| **取消** | 停止等待中或运行中的任务 |

### 产出

已完成的任务会列出它产出了什么。

| 产出 | 含义 |
|--------|---------|
| **文件** | 写入项目的一个文件 |
| **报告** | 写入项目的一份报告 |
| **对话回复** | 发布到启动该任务的对话中的一条回复 |

失败的任务带有 **错误详情**，说明原因。

### 成本

每个任务显示它的模型成本，页面还显示 **本页合计**。

| 显示 | 含义 |
|---------|---------|
| 一个金额 | 该任务发起的模型调用的估算成本 |
| **未调用模型** | 该任务没有使用模型。成本确为零 |
| **未计价** | 该模型未配置价格。成本无法估算，且并非为零 |
| **未统计** | 没有返回成本数据 |

当部分调用无法计价时，显示的数字是下限，且说明中会讲明这一点。

### 重复工作

启动一个其他成员已经启动过的阶段操作，会提示 **已由他人启动**，且不会启动任何
任务。

## 定时任务

周期性工作按项目安排。打开项目的 **运营**，或者打开 **任务队列** 页面的
**定时任务** 标签页。

1. 选择 **任务类型**。
2. 选择 **频率**：**每日**、**每周** 或 **每月**。
3. 选择 **创建**。

| 任务类型 | 产出 |
|----------|----------|
| **A1 市场报告** | 该项目的一份市场报告 |
| **B1 定位分析** | 一份定位分析 |
| **C1 合规检查** | 一份合规清单 |

每个定时任务显示它的创建人、**下次运行** 与 **上次运行**。选择 **启用** 或
**停用** 来改变它是否运行。尚未运行过的定时任务显示 **尚未运行**。

创建或开关定时任务需要审核员或管理员角色。其他成员看到的列表是只读的。

定时任务产出的报告出现在项目 **运营** 页面的 **最新运营报告** 下。

## 审核收件箱

审核收件箱保存送审待签的产物。在侧边栏打开 **审核收件箱**。侧边栏条目上带有待
审核的数量。

访问需要审核员或管理员角色。

| 标签页 | 内容 |
|-----|----------|
| **待审核** | 等待决定的条目 |
| **审核历史** | 已经决定的条目，以及做出决定的人 |

### 决定一个条目

1. 选择该条目打开其详情视图。
2. 阅读 **产物预览** 与 **任务上下文**。
3. 输入评论。评论是可选的。
4. 选择 **批准** 或 **拒绝**。

| 区域 | 内容 |
|--------|----------|
| **产物预览** | 送审的内容。内容较长时显示开头 |
| **任务上下文** | 产出它的任务的 **输入** 与 **输出** |
| **打开文件** | 在文件查看器中打开该产物 |
| **在原会话中查看** | 打开该产物所来自的对话 |
| **全部项目** | 把队列筛选到某一个项目 |

已被其他审核员决定过的条目显示 **此项已审核完成**。

拒绝一个条目不会让它的任务无处可去。该任务会回到队列，等待另一次决定。
