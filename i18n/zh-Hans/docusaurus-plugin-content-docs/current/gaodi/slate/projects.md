# 项目

一个项目是一个产品的工作区。Slate 没有多产品项目。

每个项目至少包含一个代次。一个代次是产品的一个版本，就像一台相机有第一代机型
和第二代机型。一个代次要走完六个工作流阶段。

## 创建项目

在侧边栏选择 **新建项目**。

1. 输入 **名称**。
2. 填写其余产品信息。只有 **名称** 与 **产品类目** 为必填，且类目链接会自动
   帮你填好类目。
3. 把任何初始文件拖到上传区域。
4. 确认 Slate 为每个上传文件识别出的类型。
5. 选择 **创建项目**。

Slate 会打开新建的项目。创建该项目的账户成为项目管理员。

### 项目信息

| 字段 | 用途 |
|-------|---------|
| **名称** | 中文产品名称。必填 |
| **英文名称** | 英文产品名称 |
| **型号** | 内部型号代码 |
| **产品类目** | 类目名称。除非提供了类目链接，否则必填 |
| **亚马逊类目链接** | 每行一个畅销榜或类目地址 |
| **ASIN / 商品链接** | 每行一个 ASIN 或商品地址 |
| **产品描述** | 对产品的简要描述 |
| **给 AI 的备注** | 背景、约束与偏好。会加入本项目的每一次阶段对话 |
| 参考图片 | 作为项目图标显示的图片。PNG、JPG 或 WEBP，小于 5 MB |

优先使用类目链接而不是类目名称。链接自带站点与类目节点，调研范围因此精确得多。
每个站点粘贴一条链接。

ASIN 与商品链接构成分析阶段竞品池的起点。

### 初始文件

拖到上传区域的每个文件都会被识别类型。Slate 显示它识别出的类型，并请你确认或
更正。合适的初始文件包括产品规格书、设计文件与现有的产品手册。

## 项目页面

项目页面打开时显示当前进行中的代次。

| 区域 | 内容 |
|--------|----------|
| 页头 | 产品名称、状态、类目与型号 |
| 阶段进度 | 六个阶段及其状态。每个阶段链接到对应的阶段页面 |
| 最近对话 | 本代次所有阶段中的最新对话 |
| 最近文件 | 本代次中最新的文件 |
| 代次 | 本产品的每一个代次。每个代次链接到它的设计阶段 |
| 成员 | 项目成员列表，以及每位成员的项目角色 |

## 项目子导航

在侧边栏展开一个项目，会显示四个条目。

| 条目 | 内容 |
|-------|----------|
| **市场报告** | 市场报告类型的文件 |
| **规格** | 规格书类型的文件 |
| **资产** | 品牌资产与营销图片 |
| **设置** | 项目信息、成员与代次 |

## 编辑项目

在侧边栏中打开项目下的 **设置**。

该表单包含与创建表单相同的字段。选择 **保存更改** 使其生效。只有项目管理员可
以编辑项目信息。其他成员看到的是只读表单。

## 协作

项目设置页面上的 **协作范围** 面板控制谁可以进入该项目。

| 可见范围 | 谁可以进入项目 |
|------------|------------------------|
| **私有** | 仅项目成员与范围管理员 |
| **小组可见** | 归属小组的所有成员 |
| **全公司可见** | 公司内任何人，只读 |

旁边还有两项设置。

| 设置 | 效果 |
|---------|--------|
| **归属小组** | 项目所属的部门或团队。一个项目最多归属一个小组 |
| **关联店铺** | 本产品销售所在的亚马逊店铺 |

保持为 **自动** 时，如果你加入了小组，可见范围解析为小组可见，否则解析为私有。
只有项目管理员可以更改这些设置。

## 运营

项目的 **运营** 区域涵盖上架后的工作。它包含亚马逊报表解析、周期性定时任务、
这些任务产出的报告，以及一个异常面板。

| 功能 | 可用性 |
|---------|--------------|
| 解析亚马逊搜索词报告或业务报告 | 可用 |
| 安排周期性的市场报告、定位分析或合规检查 | 可用 |
| 阅读定时任务产出的报告 | 可用 |
| 需求预测 | 不可用 |
| 广告投放管理 | 不可用 |
| 价格、评分与库存异常告警 | 不可用 |

## 限制

| 限制 | 说明 |
|------------|--------|
| 每个项目的产品数 | 一个 |
| 删除项目 | 不可用 |
| 开启新的代次 | 界面上不可用 |
| 项目类目 | 必填。类目链接可提供该值 |
| 参考图片大小 | 5 MB |
