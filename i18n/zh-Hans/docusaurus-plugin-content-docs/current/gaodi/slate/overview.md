# Slate

| | |
|---|---|
| URL | https://slate.gaodi.akn.org.uk |
| 说明 | 内部工作区，用于开发亚马逊产品，从市场调研一直做到 Listing 文案 |
| 访问 | 账户由管理员发放。注册已关闭 |
| 费用 | 内部系统，用户无需付费 |

## 概览

Slate 让员工每次针对一个产品，按六个有序阶段推进。每个阶段包含一段与模型的
对话和一组文件。模型读取项目文件，执行调研与分析，并写出供下一阶段读取的新
文件。访问与审核控制均可用，由管理员设置。

Slate 是 GDDigital 与 OMG Electronics 的内部系统。界面默认中文，并带有英文切
换。面向客户的文本以英文产出。

## 功能

| 功能 | 可用性 |
|------------|--------------|
| 为产品创建项目 | 任意账户 |
| 进行阶段对话并上传文件 | 项目成员 |
| 运行阶段流水线 | 项目操作员及以上 |
| 阅读报告、数据集与草稿 | 项目成员 |
| 对文件发表评论 | 观察者以外的项目成员 |
| 批准或拒绝送审的产物 | 审核员与管理员 |
| 新增与编辑自定义技能 | 审核员与管理员 |
| 管理用户、角色、连接与品牌套件 | 管理员 |
| 查看用量与花费 | 管理员 |
| 自行创建账户 | 不可用 |
| 删除项目 | 不可用 |
| 第 6 阶段复盘 | 不可用 |
| 需求预测与广告投放 | 不可用 |
| 价格、评分与库存告警 | 不可用 |
| 在浏览器中输入连接器密钥 | 不可用 |

## 工作流阶段

一个项目包含若干代次。一个代次按顺序走完六个阶段。阶段可以随时回头重做。

| 序号 | 阶段 | 产出 |
|--------|-------|----------|
| 1 | 设计 | 一份产品规格书 |
| 2 | 分析 | 竞品池、市场调研、利润模型、进入建议 |
| 3 | 客户之声 | 痛点报告与一份供工厂使用的数据集 |
| 4 | 迭代 | 一个修订后的规格版本 |
| 5 | 生成 | Listing 文案、产品图片与产品手册 |
| 6 | 复盘 | 不可用 |

## 角色

每个账户持有一个角色。角色由管理员设置。

| 角色 | 权限 |
|------|------|
| 操作员 | 项目、阶段对话、阶段流水线、文件、任务队列 |
| 审核员 | 操作员的全部权限，另加审核收件箱、技能库、报告模板与反馈处理 |
| 管理员 | 审核员的全部权限，另加用户、角色、连接、模型路由、品牌套件、组织目录、用量与花费 |

项目本身还带有自己的成员列表。项目成员持有四种项目角色之一：操作员、审核员、
管理员或观察者。观察者可以阅读项目，但不能对其文件发表评论。

## 登录

对于没有会话的访问者，Slate 会加载登录界面。

### 使用密码

1. 输入账户的邮箱。
2. 输入密码。
3. 选择 **登录**。

### 使用手机验证码

组织启用验证码登录后，会出现 **手机验证码登录** 标签页。

1. 选择 **手机验证码登录**。
2. 输入手机号。仅支持中国大陆手机号。
3. 选择 **获取验证码**。
4. 输入 6 位验证码。验证码 5 分钟内有效。
5. 选择 **登录**。

手机号必须先绑定到账户才能用于登录。请在 **设置** 中的 **个人资料** 里绑定手
机号。

### 使用企业微信

选择 **企业微信登录**。组织配置了企业微信登录后，该按钮才会出现。

## 会话与密码

| 属性 | 说明 |
|----------|--------|
| 会话时长 | 自登录起 7 天 |
| 语言 | 在侧边栏底部的切换按钮设置。该设置按浏览器保存 |
| 新账户 | 由管理员创建，临时密码仅显示一次 |
| 修改密码 | **设置** 中的 **个人资料**。至少 8 个字符 |

首次登录时请修改临时密码。创建该账户的管理员已经看过这个密码。
