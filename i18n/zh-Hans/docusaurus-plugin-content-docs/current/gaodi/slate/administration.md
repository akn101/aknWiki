# 管理

管理涵盖账户、组织目录、品牌套件、报告模板、技能库与花费。在侧边栏打开
**设置**。

显示哪些标签页取决于账户的角色。

| 标签页 | 谁可见 |
|-----|-----------|
| **连接** | 管理员 |
| **模型路由** | 管理员 |
| **品牌套件** | 管理员 |
| **报告模板** | 管理员与审核员 |
| **用户与角色** | 管理员 |
| **组织** | 管理员与范围管理员 |
| **反馈处理** | 管理员与审核员 |
| **知识库** | 管理员 |
| **告警与语言** | 管理员 |
| **用量与花费** | 管理员 |
| **个人资料** | 所有人 |

## 用户与角色

注册已关闭。账户在这里创建。

1. 打开 **用户与角色**。
2. 选择 **添加用户**。
3. 输入 **邮箱**、**显示名称** 与 **角色**。
4. 选择 **创建用户**。

Slate 只显示一次临时密码，之后不再显示。请通过安全渠道转交给对方，例如企业微
信私信或当面转交。切勿通过邮件或群聊发送。

| 操作 | 效果 |
|--------|--------|
| 更改 **角色** | 在操作员、审核员与管理员之间移动该账户 |
| **停用** | 阻止该账户登录 |
| **启用** | 恢复已停用的账户 |

你无法停用或降级自己的账户。

### ERP 令牌

每个账户可以带有自己的 **领星令牌**。绑定之后，该账户的 ERP 查询会使用该令牌
所能触及的店铺。令牌加密存储，保存后不再显示。

| 操作 | 效果 |
|--------|--------|
| **绑定** | 为该账户附加一个令牌 |
| **更换** | 替换已存储的令牌 |
| **清除** | 移除该令牌 |

## 组织

**组织** 标签页包含小组、店铺与权限授予。范围管理员只能看到自己管理的小组与店
铺。

### 小组

小组是一个部门或团队。一个项目最多归属一个小组。

| 字段 | 用途 |
|-------|---------|
| **名称** 与 **英文名称** | 小组名称 |
| **描述** | 该小组涵盖什么 |

每个小组带有一份成员名单。可以添加成员、把某人标记为 **组长**，以及移除已离开
的成员。不再使用的小组可以停用，而不必移除。

### 店铺

店铺是公司销售所在的一个亚马逊市场。店铺可以从 ERP 同步，也可以手动创建。

| 操作 | 效果 |
|--------|--------|
| **立即同步** | 从 ERP 拉取店铺列表，并报告新增、更新与停用了哪些 |
| **新建店铺** | 手动创建一个店铺，填写名称与市场代码 |

### 权限授予

权限授予赋予组管理员或店铺管理员的权力。选择范围类型、范围、角色与人员，然后
选择 **授予**。每一次授予都会记录授予人，并且可以撤销。

## 连接与模型路由

**连接** 列出每一个外部数据源、登录方式与存储目标，以及它们的配置状态和最近一
次成功的时间。

**模型路由** 列出每个阶段与任务使用的模型，以及其背后的回退链。

这两个标签页都是只读的。连接器密钥无法在浏览器中输入。密钥由管理员在 Slate 之
外配置。

## 品牌套件

品牌套件定义创意生成所遵循的语气与配色。

1. 打开 **品牌套件**。
2. 选择 **新建套件**。
3. 输入 **名称**。
4. 添加配色条目。按用途为每种颜色命名，并填写十六进制值。
5. 以自由文本添加语气描述。
6. 选择 **创建**。

创建套件的同时也会在知识库中创建它的目录，用于存放指南文档与参考图片。指南文
档在知识库中编辑，不在 Slate 中编辑。

仍有项目关联的套件无法删除。请把这些项目改绑到别处，或者改为停用该套件。

## 报告模板

每个报告产出器都带有一份骨架模板。标记为栏位的部分由数据填充。其余内容原样输
出。

| 操作 | 效果 |
|--------|--------|
| **插入** | 在光标处添加一个栏位 |
| **保存为新版本** | 把修改保存为新版本，可附带备注 |
| **回滚到此版** | 让较早的版本生效 |
| **恢复默认** | 回到内置模板。自定义版本仍保留在历史中 |

删除一个栏位会从报告中移除其对应章节。调整栏位顺序会重排报告。

## 技能库

技能是模型在对话中加载的书面打法手册。在侧边栏打开 **技能库**。访问需要审核员
或管理员角色。

| 种类 | 可编辑 |
|------|----------|
| **内置** | 否。内置手册随版本发布，只读 |
| **自定义** | 是 |

### 添加技能

1. 选择 **新建技能**。
2. 输入 **技能名（slug）**。仅限小写字母、数字与连字符。不能与内置手册同名。
3. 输入 **分类**、**中文名** 与一行英文 **简介**。
4. 把 **深度** 设为 **普通** 或 **深度研究**，并填写 **最少来源数**。
5. 列出 **所需工具**。不存在的工具名会被拒绝。
6. 用 Markdown 撰写正文。
7. 选择 **创建技能**。

技能的 **适用范围** 决定谁可以加载它：全公司、某一个小组或某一个店铺。

### 批量导入

选择 **批量导入**，然后拖入 Markdown 文件或 ZIP 包。

| 限制 | 说明 |
|------------|--------|
| 格式 | `.md` 文件与 `.zip` 包 |
| 每次导入的文件数 | 50 |
| 文件大小 | 500 KB |
| 重复上传同名技能 | 覆盖为新版本 |
| 包内的脚本与附件 | 不导入 |

结果会列出创建了什么、更新了什么与拒绝了什么。

## 用量与花费

在侧边栏打开 **用量**。访问需要管理员角色。

| 面板 | 内容 |
|-------|----------|
| 汇总 | 总花费、调用次数、输入 Token 与输出 Token |
| **每日花费趋势** | 按天汇总的花费 |
| **按模型**、**按任务类型**、**按项目** | 从三个角度拆分的花费 |
| **接口延迟** | 各操作近期的中位数与第 90 百分位响应时间 |

花费是以美元计的估算值。标注 **估算** 的延迟数字样本不足，使用的是预设估算。

## 反馈处理

**反馈处理** 标签页列出通过反馈按钮提交的每一条报告。可以按状态筛选、在会话中
回复提交人，并推动报告在各个状态之间流转。

| 状态 | 含义 |
|--------|---------|
| **待处理** | 还没看过 |
| **已确认** | 已阅读并归类 |
| **处理中** | 正在处理 |
| **已修复** | 已解决 |
| **暂不处理** | 未做改动即关闭 |
| **已答复** | 是一个疑问，已答复 |

## 告警与语言

**告警与语言** 包含故障转移与摘要告警的阈值，以及界面语言。语言设置同样位于侧
边栏底部。
